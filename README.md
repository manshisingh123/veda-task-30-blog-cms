# 📝 Client-Side Blog CMS

A simple and user-friendly **Client-Side Blog Content Management System (CMS)** built using HTML5, CSS3, and JavaScript.

This project allows users to create, edit, publish, save drafts, preview, filter, and delete blog posts. All posts are stored in the browser using **localStorage**, so the data remains available even after refreshing the page.

---

## 📌 Project Overview

The Client-Side Blog CMS is a frontend web application designed to provide basic blog management functionality without requiring a backend server or database.

Users can manage their blog posts directly from the browser.

---

## 🎯 Objectives

The main objectives of this project are:

- To practice CRUD operations.
- To understand JavaScript DOM manipulation.
- To work with browser `localStorage`.
- To implement Draft and Published post statuses.
- To filter posts based on their status.
- To create a responsive and user-friendly interface.
- To improve practical frontend development skills.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and functionality
- **LocalStorage** – Storing blog posts in the browser

---

## ✨ Features

### 1. Create Posts

Users can create new blog posts by entering the required information.

### 2. Edit Posts

Existing blog posts can be edited and updated.

### 3. Delete Posts

Users can delete unwanted posts after confirmation.

### 4. Draft & Published Status

Posts can be saved as:

- Draft
- Published

### 5. Filter Posts

Users can filter the blog list based on the post status.

### 6. Post Preview

Users can preview the content of a selected blog post.

### 7. LocalStorage

Blog posts are stored using browser localStorage, allowing data to remain available after refreshing the page.

### 8. Unique ID & Timestamp

Each post is assigned a unique ID and timestamp to help manage the posts.

---

## 🔄 CRUD Operations

The project implements all four basic CRUD operations:

| Operation  | Description                |
| ---------- | -------------------------- |
| **Create** | Add a new blog post        |
| **Read**   | Display saved blog posts   |
| **Update** | Edit an existing blog post |
| **Delete** | Remove a blog post         |
